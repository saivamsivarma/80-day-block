# 80-Day Block

Daily habit tracker: weighted habits with minimum versions, gym log with PRs, runs, study log, meals, bodyweight, sleep, badges, reports, CSV export, multiple challenges and optional cloud sync.

Open it on your phone at https://saivamsivarma.github.io/80-day-block/ and use Add to Home Screen. It works offline after the first visit.

Data stays in your browser unless you turn on Cloud sync (Setup → Cloud sync), which stores it in your own free Supabase project. Use Setup → Backup to copy a JSON backup, or Spreadsheet export for CSV.
