# 80-Day Block

Daily habit tracker for Oct 12 – Dec 30, 2026: habits, gym log with PRs, runs, bodyweight and sleep trends, XP and streaks.

Open it on your phone at https://saivamsivarma.github.io/80-day-block/ and use Add to Home Screen. It works offline after the first visit.

Your data stays in your phone's browser. Use Setup → Backup to copy a backup.
